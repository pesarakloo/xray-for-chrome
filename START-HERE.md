# Xray for Chrome 0.7.5

[فارسی](START-HERE.fa.md)

The GitHub package (`xray-for-chrome-v0.7.5-github.zip`) includes the extension, Windows and Mac companions, tests and English/Persian documentation. The Chrome Web Store package (`xray-for-chrome-v0.7.5-chrome-web-store.zip`) is supplied separately and contains only the extension.

## Upgrade from 0.7.4

Disconnect first. For a manual installation, replace files in the same project location and click Reload in chrome://extensions. Keep the extension installed so the same ID retains profiles, subscriptions and language. Split tunneling starts disabled with an empty list.

Existing native hosts are compatible with browser-side split tunneling. To use the pinned Mac Xray 25.8.3 download, rerun the updated Mac installer from the chosen Setup guide route.

## Publish the update

1. Update the source and regenerated downloads/ ZIPs on GitHub.
2. Upload xray-for-chrome-v0.7.5-chrome-web-store.zip to the existing store item.
3. Follow store/PUBLISH.md. The packages are prepared; this workflow has not published them.

See README.md for setup and VALIDATION.md for completed checks and remaining platform verification.
