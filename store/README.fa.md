# کروم استور — 0.7.5

[English](README.md)

فایل بارگذاری `xray-for-chrome-v0.7.5-chrome-web-store.zip` است و فقط افزونه را دارد. همان آیتم موجود استور را به‌روز کنید. پیش از به‌روزرسانی استور، ZIPهای برنامه مکمل را در گیت‌هاب منتشر کنید تا لینک‌های آموزش، نصب‌کننده درست را بدهند.

[راهنمای انتشار](PUBLISH.fa.md)، [متن استور](LISTING.md) و [نتیجه بررسی](../VALIDATION.fa.md) را ببینید. این نسخه محلی آماده شده و منتشر نشده است.

دستور `npm run release` فایل استور را کنار پوشه پروژه و بیرون از آن می‌سازد. برای انتخاب مسیر دیگر از `npm run release -- --output /path/to/store.zip` استفاده کنید. بسته سورس گیت‌هاب فایل استور یا پوشه `release/` را ندارد.
