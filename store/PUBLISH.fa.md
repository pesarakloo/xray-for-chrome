# انتشار به‌روزرسانی 0.7.5

[English](PUBLISH.md)

این به‌روزرسانی برای آیتم موجود استور با شناسه `lifddnekhjaikimaajejkdbhfnifpcoo` است. فرایند ساخت چیزی را ارسال یا منتشر نمی‌کند.

| مقصد | فایل یا پوشه |
| --- | --- |
| سورس گیت‌هاب | محتویات پوشه اصلی پروژه |
| لینک دانلود مکمل | هر دو ZIP در `downloads/` و SHA256SUMS.txt آن‌ها |
| آیتم موجود کروم استور | `xray-for-chrome-v0.7.5-chrome-web-store.zip` |
| نصب دستی در Chrome | `extension/` |

۱. پس از تغییر سورس، `npm run companion` و `npm run release` را اجرا کنید. ZIPهای تحویلی از قبل بازسازی شده‌اند.
۲. ابتدا سورس کامل و فایل‌های بازسازی‌شده `downloads/` را در گیت‌هاب منتشر کنید. بررسی کنید لینک هر دو برنامه مکمل بسته جدید را بدهد؛ راهنمای استور داخل افزونه به همین مسیرهای ثابت لینک دارد.
۳. در داشبورد ناشر Chrome Web Store همان افزونه موجود را باز کنید و `xray-for-chrome-v0.7.5-chrome-web-store.zip` را به‌عنوان بسته جدید بارگذاری کنید. آیتم تازه نسازید و ZIP کامل پروژه را بارگذاری نکنید.
۴. متن انگلیسی و ترجمه فارسی استور را بررسی کنید. تفکیک ترافیک دامنه‌ها، نیاز به برنامه مکمل و کانفیگ یا اشتراک شخصی را ذکر کنید. مجوزها تغییر نکرده‌اند.
۵. سیاست عمومی حریم خصوصی را با توضیح فهرست سایت‌های مستقیم و رفتار اتصال در PRIVACY.md و PRIVACY.fa.md به‌روز کنید. برای راهنما و تنظیم ترافیک از تصاویر نسخه جدید استفاده کنید.
۶. نصب را روی ویندوز و هر دو معماری مک با دستور کپی‌شده از خود افزونه استور بررسی کنید. اتصال واقعی، عبور مستقیم سایت فهرست‌شده، عبور سایت دیگر از پراکسی، حذف قانون و قطع اتصال را آزمایش کنید. نتیجه تست‌های این محیط در VALIDATION.fa.md است.
۷. پس از بررسی انتشار، همان آیتم را برای بازبینی ارسال کنید. انتشار سورس گیت‌هاب به‌تنهایی افزونه استور کاربران را به‌روز نمی‌کند.

ZIP مخصوص استور کلید توسعه دستی را ندارد. سورس افزونه آن کلید را برای حفظ شناسه نصب دستی نگه می‌دارد. کلید امضا یا اطلاعات ورود ناشر داخل بسته نیست.

دستور `npm run release` فایل استور را کنار پوشه پروژه و بیرون از آن می‌سازد. برای انتخاب مسیر دیگر از `npm run release -- --output /path/to/store.zip` استفاده کنید. بسته سورس گیت‌هاب فایل استور یا پوشه `release/` را ندارد.
