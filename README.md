# Xray for Chrome

A modern Chrome extension for managing Xray proxy profiles and browser-only proxy connections.

## Features

- Manage Xray profiles
- Import profiles and subscriptions
- Connection latency testing
- Windows and macOS companion support
- English and Persian interface
- Local storage of user settings

## Installation

Install the extension from Chrome Web Store or load the extension folder manually in Chrome developer mode.

The companion application is required to run the local Xray engine.
