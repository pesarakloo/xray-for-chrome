از نصب تا اولین اتصال
راهنمای ویندوز و مک، قدم‌به‌قدم

          

          
برای اتصال، افزونه + برنامه مکمل Xray + کانفیگ معتبر لازم است. برنامه مکمل جداگانه روی دستگاه نصب می‌شود و موتور اتصال را اجرا می‌کند؛ نصب افزونه به‌تنهایی کافی نیست.

          
این افزونه پراکسی را فقط برای پروفایل عادی Chrome تنظیم می‌کند؛ اتصال کل سیستم و حالت ناشناس (Incognito) را پوشش نمی‌دهد. کانفیگ یا اشتراک نیز همراه افزونه ارائه نمی‌شود.

        


        

          ۱. دریافت افزونه و برنامه مکمل
          

            
    
              
  1. برای نسخه منتشرشده، افزونه را از صفحه رسمی آن در Chrome Web Store با «افزودن به Chrome» نصب کنید. برای نصب نسخه استور، فعال‌کردن Developer mode یا Load unpacked لازم نیست.
    2. 
              
  2. بسته کامل پروژه شامل برنامه مکمل را از انتشار رسمی پروژه (بخش Releases در مخزن GitHub معرفی‌شده توسط سازنده) دریافت و از حالت ZIP خارج کنید. لینک‌های سازنده در «درباره ما» قرار دارند.
    3. 
              
  3. در بسته کامل، پوشه native-hosts شامل نصب‌کننده‌های ویندوز و مک است. فقط پوشه extension برای نصب برنامه مکمل کافی نیست؛ فایل‌های هر نصب‌کننده را کنار هم نگه دارید.
    4. 
            

            
نصب برنامه مکمل با اجرای دستی نصب‌کننده توسط شما انجام می‌شود. نصب‌کننده موتور Xray را از پروژه رسمی XTLS/Xray-core در GitHub دریافت می‌کند. نسخه برنامه مکمل باید با نسخه افزونه نصب‌شده هماهنگ باشد.

          

        


        

          
۲. نصب برنامه مکمل

          

            
            
          


          

            
ویندوز ۱۰ یا ۱۱ · Chrome 116 به بالا · .NET Framework 4.8

            
    
              
  1. اگر متصل هستید، ابتدا «قطع اتصال» را بزنید و Chrome را کاملاً ببندید.
    2. 
              
  2. پوشه اصلی بسته استخراج‌شده را باز کنید؛ همان پوشه‌ای که native-hosts داخل آن است. در نوار آدرس File Explorer عبارت powershell را بنویسید و Enter بزنید.
    3. 
              
  3. دستور زیر را در PowerShell اجرا کنید. نصب در حساب کاربری خودتان انجام می‌شود و نیازی به Run as administrator نیست. اگر Xray از قبل نصب باشد، فایل موجود حفظ می‌شود و دانلود دوباره انجام نمی‌شود.
    4. 
            

            

              
نصب در ویندوز

              
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ".\native-hosts\windows\install.ps1"

            

            
پس از پیام Installation completed successfully، Chrome را دوباره باز کنید. در تب «اتصال»، مقابل «موتور» باید نسخه Xray یا وضعیت آماده نمایش داده شود.

            

              اگر فایل دانلودشده مسدود است
              
اگر پیام «امضای دیجیتال ندارد» برای همین فایل دریافت کردید، ابتدا منبع و محتوای نصب‌کننده را بررسی کنید؛ سپس فقط همین فایل را از مسدودی دانلود خارج کرده و دستور نصب بالا را دوباره اجرا کنید:

              

                
فقط فایل نصب‌کننده

                
Unblock-File -LiteralPath ".\native-hosts\windows\install.ps1"

              

              
دستور نصب، سیاست اجرای PowerShell را فقط برای همان فرایند تعیین می‌کند. اگر دستگاه توسط سازمان مدیریت می‌شود، برای محدودیت سازمانی با مدیر سیستم هماهنگ کنید.

            

            

              اگر دانلود خودکار Xray انجام نشد
              
فایل رسمی Xray مناسب ویندوز و معماری دستگاه را جداگانه دانلود و استخراج کنید. دانلود خودکار این نصب‌کننده برای نصب تازه، نسخه v25.8.3 را دریافت می‌کند. در دستور زیر مسیر واقعی xray.exe را جایگزین مسیر نمونه کنید:

              

                
نصب با فایل محلی

                
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ".\native-hosts\windows\install.ps1" -XrayExe "C:\Path\To\xray.exe"

              

            

          


          

            
macOS 12 به بالا · Chrome 116 به بالا · مک Intel یا Apple Silicon

            
    
              
  1. اگر متصل هستید، ابتدا «قطع اتصال» را بزنید؛ سپس با ⌘ Q از Chrome خارج شوید.
    2. 
              
  2. Terminal را باز کنید. عبارت cd  را با یک فاصله بنویسید، پوشه اصلی بسته استخراج‌شده را از Finder داخل Terminal بکشید و Enter بزنید. داخل این پوشه باید native-hosts وجود داشته باشد.
    3. 
              
  3. دستور زیر را اجرا کنید. نصب‌کننده معماری Intel یا Apple Silicon را خودکار تشخیص می‌دهد. نصب در حساب کاربری خودتان است و به sudo، Xcode یا Command Line Tools نیاز ندارد.
    4. 
            

            

              
نصب در مک

              
/bin/zsh ./native-hosts/macos/install.command

            

            
بعد از پیام «نصب برنامه همراه macOS کامل شد»، Chrome را دوباره باز کنید و وضعیت «موتور» را در تب «اتصال» ببینید.

            

              استفاده از Xray دانلودشده یا نسخه مشخص
              
نصب‌کننده فعلی مک نسخه Xray را از انتشارهای رسمی GitHub انتخاب می‌کند و برخلاف ویندوز به v25.8.3 محدود نشده است. برای استفاده از نسخه مشخص، فایل رسمی xray متناسب با معماری مک را استخراج کنید و مسیر واقعی آن را جایگزین مسیر نمونه کنید:

              

                
نصب با فایل محلی

                
/bin/zsh ./native-hosts/macos/install.command --xray "/path/to/xray"

              

              
اگر همان کانفیگ با یک نسخه مشخص هسته کار کرده است، برای مقایسه از همان نسخه روی مک استفاده کنید.

            

          

          

        


        

          ۳. افزودن کانفیگ و اتصال
          

            
    
              
  1. وارد تب «افزودن» شوید. لینک‌های vless://، vmess://، ss:// یا trojan:// را هرکدام در یک خط وارد و «افزودن لینک‌ها» را بزنید.
    2. 
              
  2. برای سابسکریپشن، در همان تب نام و لینک اشتراک را وارد و «دریافت و افزودن» را بزنید. فهرست دریافت‌شده در «مدیریت» نمایش داده می‌شود.
    3. 
              
  3. در تب «اتصال» یک کانفیگ انتخاب کنید. «تست پینگ» زمان پاسخ از مسیر آن کانفیگ را نشان می‌دهد؛ سپس «اتصال» را بزنید.
    4. 
              
  4. وقتی وضعیت «متصل» شد، یک سایت را در Chrome باز کنید. برای پایان استفاده، در همان تب «قطع اتصال» را بزنید.
    5. 
            

            
تست پینگ یک درخواست HTTPS به www.gstatic.com/generate_204 از مسیر کانفیگ است. «بی‌پاسخ» می‌تواند به دسترسی به مقصد تست هم مربوط باشد. تست‌های اولیه یا قدیمی پس از بازکردن افزونه یا افزودن کانفیگ، خودکار انجام می‌شوند.

          

        


        

          رفع خطاهای رایج
          

            

              
«برنامه همراه نصب نیست»

              
این پیام ممکن است از نصب نبودن برنامه یا برقرار نشدن ارتباط با آن باشد. پایان موفق نصب، وجود Xray و بسته متناسب با افزونه نصب‌شده را بررسی و Chrome را کاملاً بسته و باز کنید.

              
«دسترسی به برنامه همراه مجاز نیست»

              
شناسه افزونه با برنامه مکمل هماهنگ نیست. بسته مکمل مخصوص همان نسخه استور را دریافت کنید؛ این مشکل با تغییر کانفیگ سرور حل نمی‌شود.

              
کنترل پراکسی در اختیار افزونه دیگری است

              
افزونه‌های Proxy یا VPN دیگر Chrome را موقتاً غیرفعال کنید و دوباره اتصال را امتحان کنید.

              
موتور آماده است، اما کانفیگ وصل نمی‌شود

              
اعتبار اشتراک، دسترسی شبکه و ساعت سیستم را بررسی کنید. از تب «اتصال»، «گزارش خطا» را باز کنید. پیش از ارسال گزارش به پشتیبانی، اطلاعات محرمانه کانفیگ را حذف کنید.

              
نصب‌کننده فایل‌ها را پیدا نمی‌کند

              
دستور را از پوشه اصلی بسته کامل اجرا کنید؛ نه از داخل ZIP یا فقط پوشه extension. فایل‌های کنار نصب‌کننده را جابه‌جا نکنید.

            

          

        


        

          حذف برنامه مکمل
          

            
ابتدا «قطع اتصال» را بزنید و Chrome را کاملاً ببندید. از پوشه اصلی بسته، دستور سیستم‌عامل خود را اجرا کنید:

            

              
ویندوز

              
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ".\native-hosts\windows\uninstall.ps1"

            

            
اگر فایل حذف ویندوز به‌علت دانلود مسدود بود، مانند بخش نصب، بعد از بررسی منبع فقط فایل uninstall.ps1 را از Properties با گزینه Unblock آزاد کنید.

            

              
مک

              
/bin/zsh ./native-hosts/macos/uninstall.command

            

            
این دستورات برنامه مکمل، هسته و فایل‌های اجرایی و گزارش‌های آن را پاک می‌کنند. حذف خود افزونه از chrome://extensions جداست و کانفیگ‌های ذخیره‌شده در افزونه را هم حذف می‌کند.
