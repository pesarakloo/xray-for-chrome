# دانلود برنامه مکمل — نسخه بسته 0.7.5

[English](README.md)

بسته‌های کوچک ویندوز و مک از تب آموزش افزونه لینک شده‌اند. مسیر کروم استور از این ZIPها و مسیر گیت‌هاب از اسکریپت‌های پروژه کامل استفاده می‌کند.

| سیستم | بسته |
| --- | --- |
| Windows 10/11 | [برنامه مکمل ویندوز](xray-companion-windows.zip) |
| macOS 12+ | [برنامه مکمل مک](xray-companion-macos.zip) |

ZIP را کامل استخراج کنید. در افزونه نصب‌شده، آموزش اتصال ← نصب از کروم استور ← سیستم‌عامل را انتخاب و دستور را کپی کنید. آن را از پوشه استخراج‌شده اجرا کنید تا شناسه درست ثبت شود. هر ZIP دارای README.txt و README.fa.txt است. هش‌ها در SHA256SUMS.txt هستند.

نصب‌کننده مک Xray 25.8.3 مناسب Intel یا Apple Silicon را می‌گیرد. ویندوز در نصب تازه 26.6.27 را دریافت می‌کند و در نصب مجدد عادی هسته موجود را حفظ می‌کند. بسته‌ها را با `npm run companion` بازسازی و هر دو ZIP و هش‌ها را همراه سورس به‌روز منتشر کنید.

برای VLESS Encryption، اتصال را قطع کنید، مکمل به‌روز را استخراج کنید و دستور «به‌روزرسانی Xray برای VLESS Encryption» را از آموزش اجرا کنید. ویندوز برای تعویض هسته موجود به `-ForceDownload` و مک به `--xray-version v26.6.27` نیاز دارد. شناسه واقعی افزونه در دستورها قرار دارد. سپس Chrome را دوباره باز کنید. Xray 26.6.27 در پروژه اصلی Pre-release است. مقدار encryption کانفیگ را تغییر ندهید.
