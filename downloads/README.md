# Companion downloads

Small installer packages for the Xray for Chrome companion app. The extension's Setup guide links directly to these files.

| System | File |
| --- | --- |
| Windows 10/11 | `xray-companion-windows.zip` |
| macOS 12+ | `xray-companion-macos.zip` |

Extract the ZIP, then double-click `install-windows.cmd` (Windows) or right-click `install.command` → Open (macOS). Each ZIP contains a short `README.txt`. Checksums are in `SHA256SUMS.txt`.

These files are generated from `native-hosts/` by `npm run companion`; do not edit them by hand.
